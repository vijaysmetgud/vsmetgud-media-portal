🎬 Media Paywall Demo

Understanding the media access payment flow

📋 Payment Rules

  • ✅ Amount: ₹100 INR per payment
  • ⏱️ Validity: 2 days from payment time
  • 👥 Applicable to: External visitors only
  • 🔓 Admin Exemption: Admins have full access without payment
  • 📱 Payment Method: QR code scan via bank/UPI
  • 🔔 Admin Notification: WhatsApp notification sent on payment
  • 💾 Database: All transactions stored persistently

🎯 Payment Flow

Step 1: Access Media

External visitor tries to download or view media content

Step 2: Paywall Triggered

System checks if media paywall is enabled and visitor has valid access

Step 3: QR Code Modal

Modal window displays bank QR code with payment instructions

Step 4: Payment via UPI/Bank

Visitor scans QR and pays ₹100 INR

Step 5: Access Granted

After payment confirmation, visitor gains 2-day access to media

Step 6: Admin Notification

Admin receives WhatsApp notification with payment details

💳 Payment Information

⏰ Validity Timeline

Day 0 - Payment Made

Visitor pays ₹100 via QR code at 2:30 PM

✓ Access granted immediately

Day 1 - Full Access

Complete 24 hours of access to all media files

✓ Can download/view without restrictions

Day 2 - Final Day

Second 24 hours of access continues

✓ Access expires at 2:30 PM (exactly 48 hours)

Day 3 onwards - Access Blocked

2 days have elapsed from payment time

✗ Must pay again to access media

🔧 Admin Controls

Administrators can toggle the media paywall feature on or off:

When Enabled: All external visitors must pay ₹100 to access media

When Disabled: All users can access media without payment (open access)

The toggle can be found in the Media Paywall Panel in the main portal (admin only)

📊 Transaction Tracking

All payment transactions are recorded in a persistent SQLite database with the following details:

Payment Timestamp

Exact date and time when payment was made

Visitor Information

Name, email, phone, device info, IP address

Transaction Details

Amount (₹100), payment reference ID, validity period

Admin Notification

WhatsApp message sent to admin (9035287965) with transaction summary
